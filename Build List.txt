This is a very common issue! When you run `terraform init`, Terraform downloads a massive plugin file for AWS (almost 700 MB) into a hidden folder called `.terraform/`. Also, the `terraform.exe` file itself is over 100 MB. 

GitHub has a strict file size limit of 100 MB, so it is blocking your push. You should never commit Terraform binaries or `.terraform` folders to Git.

I have just created a **`.gitignore`** file for you at the root of your project (`d:\Career\PEP\Pep- 2\.gitignore`). This file tells Git to ignore all `terraform.exe` files and `.terraform/` folders from now on.

### How to fix your Git error

We need to tell Git to stop tracking the large files that you already accidentally added to your local commit. Open PowerShell and run these exact commands:

**1. Go to the root of your project:**
```powershell
cd "d:\Career\PEP\Pep- 2"
```

**2. Remove the large files from Git's memory:**
*(Note: `--cached` means it removes them from Git, but keeps them safely on your hard drive so your practicals will still work).*
```powershell
git rm --cached "Day- 5/terraform_1.16.4_windows_amd64/terraform.exe"
git rm -r --cached "Day- 7/iam-user-practical/.terraform/"
```
*(If you also initialized the EC2 practical, run this one too just in case:)*
```powershell
git rm -r --cached "Day- 7/ec2-practical/.terraform/"
```

**3. Add the new `.gitignore` file and commit the changes:**
```powershell
git add .gitignore
git commit -m "Remove large terraform files and add .gitignore"
```

**4. Push to GitHub again:**
```powershell
git push origin main
```

It should now push successfully because the giant files are no longer in the commit! Let me know if you run into any other Git errors.
